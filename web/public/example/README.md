# Public example: Hikaru Nakamura

Tempo’s example is a frozen, engine-checked sample of **Hikaru Nakamura’s public Chess.com games**. Player identity is confirmed by his [Chess.com profile](https://www.chess.com/member/hikaru) and [public player API](https://api.chess.com/pub/player/hikaru).

- Source: [August 2026 public archive](https://api.chess.com/pub/player/hikaru/games/2026/08), retrieved 10 September 2026.
- Selection: the last 12 completed, rated, standard-chess blitz games in that closed month, sorted by completion time. All were played on 30 August 2026 with a three-minute time control.
- `games.json` retains the original API game objects, including PGNs, game links, timestamps, ratings, and results.
- `review.json` was generated by Tempo’s native CLI and Stockfish with 150,000 scan nodes, 1,000,000 confirmation nodes, and a 200-centipawn threshold. Its engine metadata records the executable fingerprint and complete analysis settings.
- The landing-page position in `../../assets/example-preview.json` is copied from one verified finding and its source game. It is part of this same sample, not a separately invented puzzle.

## Reproduce the review

From the repository root, reconstruct the CLI input from the bundled original PGNs:

```sh
python3 - <<'PY'
import json
from pathlib import Path

games = json.loads(Path('web/public/example/games.json').read_text())['games']
Path('/tmp/tempo-hikaru-example.pgn').write_text(
    '\n\n'.join(game['pgn'].rstrip() for game in games) + '\n'
)
PY
cargo run --locked -- review hikaru \
  --pgn /tmp/tempo-hikaru-example.pgn --last 12 \
  --output review-output/hikaru-example \
  --scan-nodes 150000 --deep-nodes 1000000 --threshold-cp 200
cargo run --locked -- validate review-output/hikaru-example/review.json
```

Stockfish must be available on `PATH`; use `--engine /path/to/stockfish` otherwise. Matching engine binaries and settings are needed to reproduce the analysis. The per-game `input_pgn_sha256` identifies the combined local PGN input used by this CLI run.
